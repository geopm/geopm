Power Sweeps
============
This directory contains scripts to generate power sweeps for use as training
data in the GEOPM PBS plugins.

Example usage inside a PBS job:

.. code-block::
    clush --nostdin --fanout="$(nodeset --count < $PBS_NODEFILE)" --hostfile="$PBS_NODEFILE" \
            env NEKBONE_RUN_DIR=/PATH/TO/DIRECTORY/CONTAINING/NEKBONE_run_mpiexec_sh \
            "${GEOPM_SOURCE}/integration/service/open_pbs/power_sweeps/sweep_nekbone_board_power.sh"

In the above example, `clush` from `ClusterShell <https://clustershell.readthedocs.io/en/latest/tools/clush.html>`_ runs an instance of the power-sweep script on each host in the PBS job. The power sweeps generate log and report files to the location specified in the `SWEEP_OUTPUT_DIR` environment variable, defaulting to `$NEKBONE_RUN_DIR/power_sweep`.

See the readme in the parent directory for documentation of `./generate_coefficients_from_reports.py`, which consumes report files generated by these power sweep scripts.
